把 agent 的记忆，做成一套可检索的文件系统。

CoMem 是面向 AI agent 的上下文记忆数据库。所有资源挂在 comem:// 虚拟文件系统下，按 L0 一句话摘要、L1 目录概览、L2 原文三层渐进披露。 这套控制台是给人用的：一条记忆从哪来、摘要是否落后、哪些主体能看见它、哪次会话把它抽出来。

01 视觉规律 从成熟开发者工具控制台提取

参考实现的共同特征是「工具不像展厅」：颜色克制、层级靠线和留白而不是阴影、标识符一律等宽、 一屏尽量多放条目。下面九条是提取出来的规律，本套页面全部按这套规则重写， 没有复用任何代码、类名或品牌资产。

01 · 单强调色
中性灰阶承担全部结构，只有一种强调色用于可交互与当前选中。状态色（成功 / 警告 / 危险 / 信息）只出现在状态位，不做装饰。
02 · 发丝线分层
所有分区用 1px 边框，不用投影堆层级。阴影只留给浮层（toast、下拉），并且很浅。
03 · 等宽承担标识符
URI、字段名、权限级别、分数、时间、计数全部等宽 + tabular-nums。数字对齐，扫读才不会错行。
04 · 小圆角
控件 6px、面板 8–10px、徽标全圆。圆角只软化边缘，不表达层级——层级由边框和背景差表达。
05 · 紧凑但可读
树行 32px、表格行 44–46px、正文行高 1.6。密度靠行高与内边距控制，不靠缩字号。
06 · 实心主按钮
主操作 36px 高、实心强调色；次操作 1px 边框 + 面板底色；危险操作独立红色，不用「红色文字 + 透明底」这种看不清的写法。
07 · 顶栏 + 三栏工作台
56px 顶栏放品牌、主导航与 scope；工作台按「列表 300 / 详情自适应 / 元数据 304」分栏，每栏独立滚动。
08 · 焦点可见
键盘焦点用 3px 半透明强调色描边，不靠浏览器默认虚线。所有可点区域都有 hover 背景变化。
09 · 双主题重新取值
浅色不是深色反相：背景、表面、边框、强调色全部重新算过，保证两套主题下正文对比度都 ≥ 4.5:1。

02 页面索引 四个工作面 + 一份规范

01 / FILESYSTEM 三层披露 ↗

文件树与详情

左树右详情。详情在 L0 / L1 / L2 之间切换，同时交代摘要由谁生成、何时生成、落后原文多少，以及重算任务是否已入队。
02 / RETRIEVAL find × search ↗

检索调试台

同一条查询分别走 find 与 search。search 先做意图分析拆成多条 TypedQuery；每条命中给出分数、层级与命中原因，并交代 ACL 滤掉了多少条。
03 / REVIEW pending ↗

记忆复核

抽取出的「经验」与「规则」在生效前必须人工过闸。左列待复核，右侧 before / after diff；规则额外展示 applies_when 与 exception。
04 / PERMISSION restricted ↗

权限管理

节点树标出 restricted 边界，右侧列主体、级别、直接还是继承，并用一条推导链说明「有效权限」是怎么算出来的。

03 色板 冷灰中性 · 单一强调色

中性色偏冷（略带蓝），在深色下不糊、不泛紫；强调色只有一个蓝，出现在链接、选中项、当前层级和焦点环上。 色块可点击复制十六进制值，括号内是该色在表面色上的对比度。

04 字号阶梯 8 级 · 最小 13px

基准正文 15px，表格 14px，标签与元信息 13px。上一版把大量内容压到 10–11px，读起来像说明书脚注； 这一版把密度交给行高和内边距，字号不再往下走。

07 做与不做

做

  • 1px 发丝线分区，靠背景差表达层级
  • URI、字段名、状态值、数字全部等宽
  • 主按钮实心，次按钮描边，危险操作独立红
  • 正文 15px、行高 1.6，密度交给行高
  • 状态点带一圈同色光晕，扫读就能定位
  • 空态给出下一步动作，而不是画插画

不做

  • 10–11px 的正文与标签（可读性不可接受）
  • 紫蓝渐变、玻璃拟态、发光装饰
  • 超过 12px 的圆角与彩色图标底板
  • 靠阴影分层的卡片堆叠
  • 把 page_id、digest 这类内部术语暴露到界面
  • 没有对比度的「红色文字」危险按钮

08 演示说明

数据
全部是手工构造的演示数据。URI 遵循 comem://{scope}/{path}，字段名与状态值对照架构文档第 6 节。
交互
目录可展开、条目可选择、层级可切换、复核可分流、权限可在 inherit / restricted 之间切换。所有改变只发生在页面内，不请求后端。
主题
右上角切换，选择写入 localStorage，5 个页面共享。
文案
界面语言中文；URI、字段名、状态值、主体标识保留英文原文，避免对接时二次翻译。
文件
index.html · filesystem.html · search.html · review.html · acl.html + 共用 app.css。无构建、无 CDN、无外部字体。
