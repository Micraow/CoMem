CoMem Console · 视觉规范 · v1.0

把 agent 的记忆，放进一个像系统设置一样熟悉的窗口。

CoMem 是面向 AI agent 的上下文记忆数据库。所有内容挂在 comem:// 虚拟文件系统下，按 L0 一句话摘要、L1 目录概览、L2 原文三层渐进披露。 这套控制台采用 macOS Sequoia / iPadOS 的原生应用观感：半透明材质、连续圆角、系统色，以及足够克制的留白。

页面 5 外观 深色 / 浅色 字体 SF Pro · SF Mono 基准 15px / 1.47 无构建 直接打开
01

页面索引

Four surfaces

四个工作面覆盖「找到、判断、过闸、授权」四件事。每个页面只回答一个核心问题，其余信息降级为辅助。

01 / FILESYSTEM 文件树 左树右详情。详情可在 L0 / L1 / L2 之间切换，并交代摘要由谁生成、何时生成、是否落后。 打开 ↗ 02 / RETRIEVAL 检索调试台 对比 find 与 search 的召回差异：意图拆出的多条 TypedQuery、每条命中的分数与层级，以及 ACL 到底过滤掉多少条。 打开 ↗ 03 / REVIEW 记忆复核 抽取出的「经验」与「规则」生效前需要人工过一道。左右并排看 before / after，规则额外展示适用条件与例外。 打开 ↗ 04 / PERMISSION 权限管理 节点树标出 restricted 边界，右侧列出主体、级别、来源，并用一条推导链解释「有效权限」是怎么算出来的。 打开 ↗

03

字号阶梯

Type scale

基础字号 15px，行高 1.47。标题用负字距收紧，SF Pro 在大字号下不需要额外加宽。全站最小字号 13px，且只用于极短标签。

材质与圆角

Materials & shape

侧边栏、工具栏、底部操作条使用同一套半透明材质：blur(30px) saturate(180%) 加半透明底色。 材质只用来表达层级——它出现在固定的外壳上，不用于内容卡片。

06

做与不做

Do / Don't

Apple 的克制是有代价的：每多一种装饰，就少一分可读性。下面几条是这一版反复校对的底线。

做
  • 正文 15px、行高 1.47，表格 14px；最小 13px 只给短标签。
  • 主要操作是填充色 + 白字，高度 36px；次要操作给半透明底。
  • 用大间距（24–32px）分组，而不是往每块之间塞分割线。
  • URI、字段名、状态值、数字一律等宽字体 + 表格数字。
  • 侧边栏和工具栏用同一套半透明材质，滚动时内容从下面透出来。
  • 动效只做位移与透明度，尊重 prefers-reduced-motion。
不做
  • 不用 10–11px 的「信息密度字号」，那是把可读性换成假装的精致。
  • 不用紫蓝渐变、发光球体、彩色图标底板。
  • 不在界面里暴露开发期内部字段名，用「基线」「待刷新」这类说法。
  • 不用颜色单独表意：状态一定同时带文字或形状。
  • 不用纯阴影表达层级，也不用大于 24px 的圆角。
  • 不把交互藏在悬停里，所有操作都有可见入口。
07

结构约定

Layout rules
间距刻度
4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 56。组件内 12/16，区块间 24/32，页面级 40/56。
行高
树行 30px、表格行 44px、列表行 52px。密度靠行高与留白控制，不靠缩字号。
外壳
侧边栏 238px + 主区自适应；内部分栏 320px。主区独立滚动，外壳固定。
栅格
4px 基准。详情页正文列上限 1120px，右栏 300px，长文行长 68ch。
主题
默认深色，localStorage 记忆选择，跨页面保持；两套外观独立校对对比度。
文案
界面语言中文；URI、字段名、状态值、主体标识保留英文原文，避免对接时二次翻译。
